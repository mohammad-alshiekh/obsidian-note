# Jailbreaking Notes

## 📝 Professional Summary
Jailbreaking bypasses a model's safety alignment to obtain restricted output. Differs from injection: it targets the model's rules, not the app's instructions.

## 🎯 Learning Objectives
* Understand jailbreak categories
* Recognise common techniques
* Know detection and mitigation options

## 🧠 Key Concepts
* Role-play / persona (e.g. DAN-style)
* Hypothetical and fictional framing
* Obfuscation: encoding, translation, token splitting
* Multi-turn escalation
* Payload splitting

## 🛠️ Tools & Commands Used
* Manual prompt testing
* Red-team frameworks

* Input/output classifiers

## 💡 Key Takeaways
* Jailbreaks evolve constantly; defence is layered
* Injection = attack on application, jailbreak = attack on model policy
