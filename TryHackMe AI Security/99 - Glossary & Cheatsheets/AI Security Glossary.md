# AI Security Glossary

| Term | Definition |
|---|---|
| AI-BOM | Inventory of models, datasets and libraries used by an AI system |
| Adversarial example | Input crafted to make a model misbehave at inference |
| Alignment | Training a model to follow safety and human intent |
| Backdoor | Hidden trigger that causes attacker-chosen behaviour |
| Context window | Total text (system + user + retrieved) the model sees |
| Embedding | Numeric vector representing meaning of text |
| Excessive agency | LLM given too many permissions or tools |
| Guardrails | Filters and rules around model input/output |
| Hallucination | Confident but false model output |
| Indirect prompt injection | Malicious instructions hidden in external content |
| Jailbreak | Bypass of a model's safety alignment |
| Membership inference | Determining if a record was in the training set |
| Model extraction | Stealing a model by querying it |
| Model inversion | Reconstructing training data from a model |
| Pickle | Python serialization format that can execute code on load |
| Poisoning | Corrupting training or retrieval data |
| Prompt injection | Crafted input that overrides intended instructions |
| RAG | Retrieval-Augmented Generation |
| Safetensors | Weights-only, safe model format |
| System prompt | Hidden developer instructions to the model |
| Token | Unit of text processed by an LLM |
| Vector database | Store for embeddings with similarity search |
